# Image Frame Asset Sources

All imported frame assets in this folder are from sources that explicitly publish the assets under Creative Commons Zero (CC0) or public domain terms.

- `kenney-fantasy-ui-borders`: modular 9-slice fantasy UI borders from Kenney.
- `screaming-brain-portrait-frames`: selected material portrait frames from Screaming Brain Studios, converted from magenta-keyed centers to transparency.
- `system-g6-rpg-ui`: selected dark frame crops from System G6's RPG UI set.
- `zwonky-parchment-gui`: selected parchment and dark panel 9-patch crops from zwonky's Parchment GUI set.
- `nicubunu-golden-border`: ornate golden SVG border from nicubunu.
- `fabinhosc-jungle-vines`: jungle vine accents for future nature, jungle, or temple frame variants.

The Homebrewery CSS currently maps faction classes to selected assets from these libraries rather than using a single generic frame source for every faction.
