# Image Frame Asset Sources

All imported frame assets in this folder are from sources that explicitly publish the assets under Creative Commons Zero (CC0) or public domain terms.

- `kenney-fantasy-ui-borders`: modular 9-slice fantasy UI borders from Kenney.
- `screaming-brain-portrait-frames`: selected material portrait frames from Screaming Brain Studios, converted from magenta-keyed centers to transparency.
- `system-g6-rpg-ui`: selected dark frame crops from System G6's RPG UI set.
- `zwonky-parchment-gui`: selected parchment and dark panel 9-patch crops from zwonky's Parchment GUI set.
- `nicubunu-golden-border`: ornate golden SVG border from nicubunu.
- `fabinhosc-jungle-vines`: jungle vine accents for future nature, jungle, or temple frame variants.
- `gargargarrick-blue-decorated-window`: ornate blue/gold fantasy window from gargargarrick, converted to a transparent-center frame.
- `shadow3097-window-frame`: selected large window frames from Shadow3097, converted to transparent-center frames.
- `stumpystrust-fantasy-ui-box`: demonic/dark fantasy box frames from StumpyStrust, converted to transparent-center frames.
- `nicubunu-dark-border`: dark/evil SVG border from nicubunu.
- `nicubunu-golden-emerald-border`: gold/emerald SVG border from nicubunu.
- `buch-golden-ui`: small CC0 golden UI sheet from Buch, preserved as an accent source.

The Homebrewery CSS maps faction classes to different source asset families and accent treatments rather than using a single generic frame source for every faction.
