# Screaming Brain Studios Portrait Frame Pack

Source: https://opengameart.org/content/portrait-frame-pack

Author: Screaming Brain Studios

License: Creative Commons Zero (CC0) 1.0 Universal.

This folder contains selected 256x256 frames from the 128x128 portrait frame pack. The upstream pack uses magenta keyed centers; the selected files here have that magenta converted to transparency for CSS `border-image` use.
